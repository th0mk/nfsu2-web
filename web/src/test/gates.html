Speed trap gate editor

Normally, open F9 → Development → Gate editor while driving. This optional launcher starts a separate career and private room for placement work.

  1. Choose Start editor, then Play. Allow about 80 seconds for the introduction.
  2. Open Gate editor. Drag the live overhead view to pan; scroll to zoom. The starting altitude is 100 m.
  3. Choose New gate and click both road edges. Select gates in the sidebar to edit or delete them.
  4. Edits save automatically to the repository catalog and apply to dev server scoring. Use Start on side 1 / 2 to drive through a gate.
