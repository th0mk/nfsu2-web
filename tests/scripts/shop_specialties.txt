# The Car Specialties shop (UI_ICEMAIN.fng) as the game has it, from two Discord reports: after a custom gauge is
# bought Stock cannot be picked again, and Back out of Trunk Audio puts the category list on its first item.  Both
# are the game's own code with its own data (no override or hook of ours on the way; runs the same with and without
# the vinyl and mod packs), shown here with the state that decides them:
#  - Custom Gauges (UI_ChooseCustomHUD.fng, constructor 0x56C210, messages 0x563CF0): the list always starts at its
#    first item, Stock (0x53C1F0 selects the first; nothing selects the part fitted), and the constructor sets the
#    screen's stage [0x838560] to 1 (the style list; 2-4 the colour pickers, 0 once the colours are picked).  Enter
#    (0x564135) asks the style's attribute 0x311151F8 (Stock 0, the others 1-10 in GLOBALB's part database): at a
#    stage above 0 a style with colours opens the colour pickers, and Stock does nothing.  The bought gauge stays
#    fitted: the car record's slot 163 (CUSTOM_HUD) keeps its key, so leaving the shop keeps it.
#  - The category lists keep their place per package, in the screen table's row (UI_ICEMAIN.fng: 0x7F890C, +0x10 the
#    place plus 1, 0 none: the first; written as the selection moves, 0x543D40, read when the list is made, 0x5593E0).
#    Trunk Audio is a second UI_ICEMAIN.fng screen (its one category, Trunk Layout) on the same row, and its Back
#    (0x568C90: a list of a kind other than the shop's own, [0x838998] not 0) writes 0 there before going back, so
#    the shop's list is made again (UI_ICEMAIN.fng anew) at its first item, Custom Gauges.  Nitrous Purge and the
#    others open on top of the list, which keeps its place.
# Frames: np_back (Nitrous Purge kept), ta_in, ta_back (Custom Gauges), g_bought, g_again (Stock shown), g_stock_enter
