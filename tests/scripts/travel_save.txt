# Saving on a race track's map (runtime/travel.c, savegame.c): the pause menu's Save there keeps the city's place the
# car left in the career (+0x8750; a save made there loads in the city, in the stock game too); then the pause menu's
# Quit (it keeps the car's place, 0x513B30: the menus leave the city's), Resume Career and the crib's Return to Explore
# Mode (the game's own way back, which saves again with Autosave on): free roam in the city at that place.
#   roam-pair --solo --seed <a stage-2 career save> --a Sav:travel_save.txt --env NFSU2_ROAM=1
#             --env NFSU2_ROAM_WEBTEST=vlan --env NFSU2_ROAM_ROOM=<own>

+0    tap ESCAPE

+0    log LOG saved_on_track
+60   expect f:0x863490 == @px          # the career keeps the city's place

+0    waitfe UI_CareerCrib.fng 3000
