# Most Wanted: a pursuit in free roam, from its start to its end (TRACKER M4-16, first part).  Seeded with the save
# tree career_start.txt leaves (as career_resume.txt is), this run resumes the career into free roam, starts a
# pursuit with Game.ForcePursuitStart(1) (0x60AAC0, the Lua binding the game's own scripts start pursuits with: it
# posts MForcePursuitStart to the AICopManager), lets the game's AI drive the player's car (`autopilot on`), and
# waits on the game's state: the pursuit object on the car's AI interface (`pursuit wait on`), then its end
# (`pursuit wait off`, runtime/mw/career_mw.c log_pursuit).  `pursuit watch` logs every change of the pursuit state
# ([mwpursuit] lines: heat, the pursuit object, its length).  In the wave-7 runs a pursuit started this way ended
# after about 25 s with the post-pursuit screen PostRace_MilestoneRewards.fng, the car parked or driven (busted or
# escaped: which one, not identified yet); the heat stayed 1.00.  The [status] lines give the frame rate in it.
#   NFSU2_SAVE_SEED=DIR/career_start node web/tools/run-suite.mjs --game mw --script pursuit_start.txt \
#     --marker 'pursuit_start: ended' --env NFSU2_QUIT_FRAMES=20000
