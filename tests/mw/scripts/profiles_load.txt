# Most Wanted: the second of three runs (TRACKER M3-20), seeded with the save tree profiles_make.txt left: ALPHA and
# BRAVO.  A start with saves shows the Load list (MC_List.fng) before the main menu; the game lists the aliases in
# the order FindFirstFileA gives them, which is NTFS's on Windows (runtime/fileio.c, game.h find_sorted), so ALPHA
# comes first.  This run loads ALPHA there, saves it from the Alias Manager (a save writes the current alias, so the
# write of ALPHA/ALPHA shows the load took), loads BRAVO from the Alias Manager and saves it, then deletes ALPHA.
# Every step acts on its screen or dialog (L-021): the dialogs inside MC_Main.fng by what it shows and highlights,
# the list's rows by name, highlighted (kb_alias.txt says how; runtime/mw/fe_mw.c mw_fe_match).  The list leaves
# in the frame its Enter is taken and the dialog under it shows the answer a frame or two later, while that Enter
# is still held (a tap holds a key 6 frames): the dialog's own Enter waits 8 frames, or the game would see one press.
# The Alias Manager (MC_ProfileManager.fng): Create, Load, Save, Delete (0x4B4E388A on), left to right, no wrap; it
# keeps its highlight under the dialogs.  The dialogs:
#   the boot list: Enter on ALPHA; "Load complete.": Enter, the main menu;
#   Save: "Are you sure you want to save the alias named ALPHA?" (No highlighted): Left, Enter; "Do you want to
#   overwrite previously saved game?" (No): Left, Enter; "Save complete.": Enter;
#   Load: "Loading a new alias will result in the loss of any unsaved changes to the current alias. Are you sure
#   you want to load a new alias?" (label 0x87C7577E, No): Left, Enter; the list: Down to BRAVO, Enter; "Load
#   complete.": Enter;
#   Delete: the list: Enter on ALPHA; "Are you sure you want to delete ALPHA?" (No): Left, Enter; "Save game
#   deleted.": Enter.
