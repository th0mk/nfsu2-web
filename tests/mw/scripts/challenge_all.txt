# Most Wanted: every Challenge Series event once, won through the aid and saved (TRACKER M4-21).  Seeded with the save
# tree profiles_make.txt leaves (ALPHA and BRAVO; NFSU2_SAVE_SEED), it loads ALPHA (as race_win.txt does), opens the
# Challenge Series and plays its 69 events in the list's order, 1 to 69, each opened by the wins before it, then saves
# ALPHA from the Alias Manager (as race_win.txt does).
# The list (ChallengeSeries.fng, "N / 69": the counter's strings "N" and "69", label 0x18, and "/") is a grid four
# events wide (RIGHT steps one, DOWN four) and opens on event 1 (the game goes back to the main menu after every event);
# its events are the race bin 0x13's in their order (0x7AE950), which holds 70: the list leaves out the 69th, 19.8.31
# (challenge_burgerking, a sprint that never opens), and shows the 70th, 19.9.70 (challenge_35_collectors_ edition, the
# Black Edition's pursuit challenge, open from the start: "In this event you will be pursued by ...") as its 69th, alone
# on the last row (the counter's "69" is also its total, so that one is found by its text); `challenges` logs each
# event's EventID and its progress flags in GRaceDatabase's table (runtime/mw/career_mw.c: flag 4 open, flag 1 won, as
# seen: a new alias has events 1 and 2 open, and the win of event 1 opens events 3 and 4).  An event: Enter, the launch
# dialog ("Are you sure you want to launch this event?": its default 0xB8A7C6CD declines, its other button 0xB8A7C6CC
# launches), automatic gears, the race (GameFlow 6) and its GO, raceinfo (the event's EventID, its type: 4 tollbooth, 8
# pursuit; the car the challenge gives), then, 300 frames after GO, the aid's win: challengewin, the call the
# challenge's script makes when its goal is met (Game.ChallengeComplete: the racer's goal byte), then racewin's finish
# (NotifyRaceFinished, SetHasBeenWon, EnterPostRaceFlow).  The goal itself (a time, cops destroyed, a pursuit's length
# ...) is not played for: the game's own post-race code then records the win and opens the next events.  The end
# screens: after a tollbooth the winner's InGamePhotoMaster.fng, whose Enter goes back to the list; after a pursuit
# PostRace_MilestoneRewards.fng (FadeScreen.fng stays above it, so it is not waited for by name), Enter,
# PostRace_Pursuit.fng (the pursuit's counts), Enter, the game's autosave (InGame_MC_Main.fng "Saving ALPHA") and the
# main menu on Challenge Series, whose Enter opens the list again.  Enter is pressed until the list is back, and the
# check finds the end screens in the NFSU2_FNG_LOG=1 lines.  The counter waits use '~18/N' (fe_mw.c: label 0x18 and the
# whole text N), so "6" is neither "69" nor a "6" elsewhere on the screen.
