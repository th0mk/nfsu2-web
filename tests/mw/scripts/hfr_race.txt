# Most Wanted at other frame rates, lockstep A/B (TRACKER M7-21, M7-22; runtime/mw/framerate_mw.c, hfr_mw.c).
# race_frames.txt's Custom Race circuit (City Perimeter, 3 opponents) with Traffic Level at Maximum (two RIGHTs
# from Minimum), the game's AI driving the player's car from GO, then 90 s of the simulation's time (the Sim
# timer [0x9203B0] +0x18, steps x step) and the race's status.  With NFSMW_HFR_TRACE=1 runtime/mw/career_mw.c
# logs the racers and every vehicle's speed every 0.25 s of game time from GO, so runs at different rates line
# up: tools/mw/hfr_ab.py REF.log RUN.log... compares them (the player's car, the racers' progress, the traffic's
# stops).  NFSMW_HFR_AILOG=1 adds the traffic AI's target speed for cars under 0.6 m/s.  Lockstep makes each
# frame exactly one slot of game time (NFSU2_HFR_LOCKSTEP=1); the race still differs from run to run at the
# same rate (GO's step, the AI), so compare several runs a rate:
#   node web/tools/run-suite.mjs --game mw --script hfr_race.txt --marker 'hfr_race: 90 s of game time' \
#     --env NFSU2_HFR_LOCKSTEP=1 --env NFSU2_FPS=120 --env NFSMW_HFR_TRACE=1 --timeout-scale 6
# (an oracle build also needs the D3DX seed of tests/mw/scripts/boot_menu.txt)
