# Most Wanted: what the game draws for its effects in a race (TRACKER M5-15..M5-20): race_shots.txt's Custom Race
# circuit (City Perimeter, the first car, automatic gears), the video options logged at the front end, then the
# device-call recorder (NFSU2_DXREC, docs/web/dxrec.md) writes three windows of 3 Presents each: at GO, after 300
# frames of the game's AI driving (autopilot) and once the player's car goes 120 km/h or more (the AI leaves the line
# after a few seconds), each with the player's speed ("where").  The options
# come from the registry the run starts from (tests/mw/seed/: registry_max.txt, or one of the fx_*.txt seeds that
# turn one effect off), so a pair of runs shows one effect on and off.  web/tools/fx-census.mjs counts what each
# window holds: draws per effect and technique, render targets, StretchRect copies, occlusion queries and readbacks.
#   node web/tools/run-suite.mjs --game mw --script fx_census.txt --marker 'fx_census: done' \
#     --reg /tests/seed/registry_max.txt --env NFSU2_DXREC=/save/dxrec.txt,999999999 --save-out <dir>
#   node web/tools/fx-census.mjs <dir>/fx_census/dxrec.txt
# NFSU2_DXREC's window 999999999 writes nothing until the script's first "dxrec".  An oracle build needs
# boot_menu.txt's D3DX seed (NFSU2_SAVE_SEED and --env NFSMW_D3DX=/save/d3dx9_26.dll), or --env NFSMW_D3DX_FX=hle.
