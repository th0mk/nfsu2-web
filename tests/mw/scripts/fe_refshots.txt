# splash package ($O, game.h fe_object; an object's colour alpha is the int at [object+0x2C]+0xC,

# whose script the splash's code starts, 0x5A3147) fades in to full and pulses from there.  Frame counts are only
# settling time on a screen that is up, and the highlight's moves within one, which bring up no screen.
# It needs the renderer: the play page (test/play.html), not run-suite's hostcheck page, e.g.
#   test/play.html?wasm=/game.wasm&arg=/data/speed.exe&script=/tests/scripts/fe_refshots.txt
#     &artifacts=/artifacts/fe_&dumpscale=1&w=1280&h=720&env=NOMOVIES=1&env=GPUVS=1&env=NFSU2_FNG_LOG=1 ...
# from a server started with --dev --artifacts <dir> --game mw, in an oracle build (tests/mw/scripts/boot_menu.txt
# says how the page gets d3dx9_26.dll: NFSMW_D3DX=/save/d3dx9_26.dll and a seeded save folder).  The pictures are
