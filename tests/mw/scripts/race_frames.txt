# Most Wanted: the per-frame anchor in a race (TRACKER M4-01, Q-24).  Core runs MW's on_frame at MainLoop's
# 0x663EC6, between the game's update and its render (runtime/mw/game_mw.c MW_FRAME_SITE; runtime/debug.c
# guest_hook counts the passes), and the race aids (runtime/mw/career_mw.c) run there.  The race must last the
# whole window, so it is not the random Quick Race (a drag race of it ended 3,400 frames after GO) but a Custom
# Race circuit: the main menu's Quick Race (its 3rd item, 0x4B4E388C), Custom Race (the "quick race" menu's 2nd
# item), Circuit ("custom race mode select"'s first), its first track, City Perimeter (9.9 miles; 1,200 frames of
# the AI driving came to 1.9 % of it), the circuit options as they come, the car the car list starts on and
# automatic gears ("Select your transmission": Auto).  It waits for the race (GameFlow 6) and for GO: the
# player's race timer runs (GRaceStatus [0x91E000], its first racer's GRacerInfo at +0x18, whose byte +0x154 says
# its timer runs: GRaceStatus +0x16C).  The game's AI then drives the player's car (autopilot) for 10,000 frames,
# and the script logs the Presents and the anchor's passes at both ends, then the race's status;
# tests/mw/checks/race_frames.sh wants one pass a Present over them, give or take one, and the race still on at
# the end (no racer finished, no post-race screen in the window):
#   node web/tools/run-suite.mjs --game mw --script race_frames.txt --marker 'race_frames: 10000 frames' \
#     --env NFSU2_QUIT_FRAMES=20000 --timeout-scale 3
# (an oracle build also needs the D3DX seed of tests/mw/scripts/boot_menu.txt)
0     waitmem 0x00925e90 3 3600       # the front end (GameFlow 3)
+0    tapuntil RETURN MainMenu.fng 90 6000
+0    waitfng MainMenu.fng@4b4e388a 600                  # the main menu takes input, on Career
+0    tapuntil RIGHT MainMenu.fng@4b4e388c 40 600        # Quick Race
+0    tap RETURN
+0    waitfng MainMenu_Sub.fng:cdf0cc03@4b4e388a 600     # "quick race", on its random Quick Race
+0    tapuntil RIGHT MainMenu_Sub.fng:cdf0cc03@4b4e388b 40 600   # Custom Race
+0    tap RETURN
+0    waitfng MainMenu_Sub.fng:1f203817@4b4e388a 600     # "custom race mode select", on Circuit
+0    tap RETURN
+0    waitfng Track_Select.fng:3de80a85:4d36bf77 600     # "circuit track select", on City Perimeter
+0    tap RETURN
+0    waitfng Track_Options.fng:a6ed015d@b2980ba8 600    # "circuit options", as they come
+0    tap RETURN
+0    waitfng Car_Select.fng:d18d600a 600                # the car list (its "TOP SPEED" up)
+0    tap RETURN
+0    waitfng Dialog.fng:8cd532a0@b8a7c6cd 600           # "Select your transmission", on Auto
+0    tap RETURN
+0    waitmem 0x00925e90 6 6000                          # racing (GameFlow 6)
+0    waitexpr b:[0x0091e000]+0x16c != 0 3000            # GO: the player's race timer runs
+0    log race_frames: GO
+0    autopilot on
+0    frames
+10000 frames
+0    log race_frames: 10000 frames
+0    racestatus
+0    close
