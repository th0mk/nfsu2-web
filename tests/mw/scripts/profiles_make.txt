# Most Wanted: the first of three runs that make, load and delete aliases across restarts (TRACKER M3-20; the save
# tree each run leaves seeds the next: profiles_load.txt, then profiles_gone.txt).  This one, from a first start,
# makes ALPHA and saves it (as kb_alias.txt makes ROTEST), then makes BRAVO with the Alias Manager's Create and saves
# that too.  The dialogs are inside MC_Main.fng, so the gaps count frames.  The steps after the first alias:
#   the main menu's Alias Manager (its 7th item) opens MC_ProfileManager.fng: Create, Load, Save, Delete, left to
#   right (no wrap); Create asks "Creating a new alias will result in any unsaved changes to the current alias being
#   lost. Are you sure you want to create a new alias?" (No highlighted): Left, Enter; the two autosave notes:
#   Enter, Enter; "Enter name: NAME": Backspace x4, BRAVO, Enter (Accept); "Do you want to save the alias BRAVO?"
#   (No highlighted): Left, Enter; "Save complete.": Enter, back to the Alias Manager with BRAVO the current alias.
# tests/mw/checks/profiles_make.sh wants both saves written, in that order:
#   node web/tools/run-suite.mjs --game mw --script profiles_make.txt --marker 'profiles_make: BRAVO saved' \
#     --env FILELIST=1 --env NFSU2_QUIT_FRAMES=9000 --save-out DIR
# (an oracle build also needs the D3DX seed of tests/mw/scripts/boot_menu.txt; DIR/profiles_make/ then holds the DLL
# too, so it seeds the next run as it is)
0     waitmem 0x00925e90 3 3600       # the front end (GameFlow 3)
+0    tapuntil RETURN MC_Main.fng 90 3000
+300  tap LEFT                        # Create a new alias?  Yes
+100  tap RETURN
+300  tap RETURN                      # the autosave notes
+300  tap RETURN
+300  loop 4                          # Enter name: NAME
+0    nstap BACK
+20   endloop
+60   nstype ALPHA
+120  tap RETURN                      # Accept
+300  tap LEFT                        # save the alias ALPHA?  Yes
+100  tap RETURN
+300  tapuntil RETURN MainMenu.fng 90 3000    # Save complete.  Continue
+0    waitfng MainMenu.fng 600
+0    log profiles_make: ALPHA saved
+300  loop 6                          # Career .. Alias Manager
+40   tap RIGHT
+0    endloop
+60   tap RETURN

+120  tap RETURN                      # Create
+300  tap LEFT                        # unsaved changes lost, sure?  Yes
+100  tap RETURN
+300  tap RETURN                      # the autosave notes
+300  tap RETURN
+300  loop 4                          # Enter name: NAME
+0    nstap BACK
+20   endloop
+60   nstype BRAVO
+120  tap RETURN                      # Accept
+300  tap LEFT                        # save the alias BRAVO?  Yes
+100  tap RETURN
+300  tap RETURN                      # Save complete.  Continue
+300  log profiles_make: BRAVO saved
